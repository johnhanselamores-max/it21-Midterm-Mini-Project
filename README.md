Browser Navigation Simulator

Project Description

The Browser Navigation Simulator is a Java-based application that demonstrates basic browser navigation features using Object-Oriented Programming.

Features

-Visit a website
-Go back to a previously visited website
-Search browsing history
-Display browsing history

Technologies Used

-Java
-Apache NetBeans IDE
-Git and GitHub

How to Run

-Open the project in Apache NetBeans.
-Locate the BrowserApp.java file.
-Run the main class.
-Follow the instructions displayed in the console.
